## 🛠️ How to Use
This playbook is organized by attack phases. Each category contains Markdown files detailing specific techniques, commands, and OPSEC considerations.

### Example Usage:
- Navigate to a phase (e.g., `05-Privilege-Escalation`).
- Read the relevant technique (e.g., `Windows-PrivEsc.md`).
- Follow the methodology and adapt the commands to your target environment.
